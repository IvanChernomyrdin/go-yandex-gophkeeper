# GophKeeper — Менеджер паролей

## Описание

CLI-приложение для безопасного хранения приватных данных: логинов, паролей, банковских карт, текстовых и бинарных данных. Поддерживает работу на Windows, Linux и Mac OS.

Пользователь может использовать несколько устройств — данные синхронизируются и остаются актуальными на всех.

---

## Функциональность

- Регистрация и вход с выдачей JWT-токена
- Автоматическое обновление JWT-токена
- Добавление, просмотр, редактирование и удаление данных:
  - пары логин/пароль
  - текстовые данные
  - бинарные данные
  - данные банковских карт
- Шифрование данных по мастер-паролю
- Синхронизация между несколькими устройствами

---

## Как это работает

1. Пользователь регистрируется, получает JWT-токен.
2. Все данные перед отправкой на сервер шифруются с использованием мастер-пароля.
3. При добавлении или изменении данных клиент отправляет запрос на сервер.
4. При входе с другого устройства данные подтягиваются актуальные.
